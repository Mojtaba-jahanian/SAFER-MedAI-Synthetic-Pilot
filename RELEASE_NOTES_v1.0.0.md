# v1.0.0 — Stage 02C-1 frozen synthetic pilot

**Release-notes draft for the first public GitHub Release.** This text does not imply that the release or Zenodo DOI has already been issued.

This archival software version includes the frozen 02B design, original Stage 02C-1 simulation implementation, 7,000 recorded synthetic policy/world/seed/budget episodes, seed-level action traces and integrity manifests. The code, synthetic observations and associated documentation are released under the **MIT License** (see `LICENSE`).

**Prespecified primary negative result:** averaged equally over the W3 reference-gap and W4 support-gap worlds, P4 minus P5 valid/correct resolution rate was **-0.50** at the 2,600-unit budget. The prespecified +0.05 pilot GO threshold failed and the subsequent 1,000-seed confirmation was **not** run. The pre-pilot P6 code correction is documented.

This release does not include patient-level medical datasets, clinical images, protected patient identifiers, original fitted NIH imaging model parameters or historical ECG inference artifacts. It is **not** a clinical decision-support system, hospital-shift validation or demonstration of superior evidence acquisition.
